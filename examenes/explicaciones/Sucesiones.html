Regla de Oro #1

Sucesiones Aritméticas (Diferencia Constante $d$) ➕

En una sucesión aritmética, cada término se obtiene sumando una diferencia fija $d$ al anterior:

$$a_n = a_1 + (n - 1)d = d \cdot n + (a_1 - d)$$
💡 Atajo PAA de la tabla de multiplicar: Si la sucesión sube de 4 en 4 ($d = 4$), la fórmula empieza con $4n$. Luego ajustas con el término cero ($a_0 = a_1 - d$).
Ejemplo: $5, 9, 13, 17...$ ➔ Sube de 4 en 4 ➔ $4n$. Para $n=1$, $4(1) = 4$, falta 1 para llegar a 5 ➔ Fórmula: $4n + 1$.
Ejemplo Guiado #1

Ejemplo Resuelto: El Término Lejano 🔍

Reactivo Modelo PAA:

En la sucesión aritmética $7, 12, 17, 22, ...$, ¿cuál es el valor del término en la posición 40 ($a_{40}$)?

✅ Solución Paso a Paso:
1. Identificar diferencia: $12 - 7 = 5$ ➔ $d = 5$.
2. Primer término: $a_1 = 7$.
3. Fórmula: $a_n = 5n + (7 - 5) = 5n + 2$.
4. Para $n = 40$: $a_{40} = 5(40) + 2 = 200 + 2 = \mathbf{202}$.

Regla de Oro #2

Sucesiones Geométricas (Razón Multiplicativa $r$) ✖️

Cada término se obtiene multiplicando por una razón constante $r$:

$$a_n = a_1 \cdot r^{n-1}$$
Ejemplo: $3, 6, 12, 24, 48...$ ➔ Se duplica en cada paso ($r = 2$).
Para el 6º término: $a_6 = 3 \cdot (2^5) = 3 \cdot 32 = 96$.
Ejemplo Guiado #2

Ejemplo Resuelto: Patrón Fraccionario Geométrico 🔍

Reactivo Modelo PAA:

¿Cuál es el siguiente número en la sucesión: $\frac{1}{2}, \frac{3}{4}, \frac{9}{8}, \frac{27}{16}, ...$?

✅ Solución Paso a Paso:
1. Analiza el numerador: $1, 3, 9, 27$ ➔ Se multiplica por 3 ($27 \times 3 = 81$).
2. Analiza el denominador: $2, 4, 8, 16$ ➔ Se multiplica por 2 ($16 \times 2 = 32$).
3. La razón geométrica es $r = \frac{3}{2}$.
4. Siguiente término = $\frac{27}{16} \times \frac{3}{2} = \mathbf{\frac{81}{32}}$.

Machete PAA

Machete de Sucesiones 📋

Aritmética = Suma fija
Fórmula rápida: $d \cdot n + a_0$. Donde $a_0 = a_1 - d$.
Geométrica = Multiplica
Fórmula: $a_n = a_1 \cdot r^{n-1}$.
Fracciones Independientes
En sucesiones de fracciones, analiza numeradores y denominadores por separado.
Comprueba con $n=1$
Sustituye $n=1$ en tu fórmula para comprobar si da exactamente el primer término.
