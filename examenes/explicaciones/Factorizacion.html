Regla de Oro #1

Diferencia de Cuadrados: La Joya de la PAA 💎

Aparece en casi todos los exámenes: dos términos con signos opuestos que son cuadrados perfectos:

$$a^2 - b^2 = (a - b)(a + b)$$
Ejemplos inmediatos:
$x^2 - 16 = (x - 4)(x + 4)$
$4x^2 - 25y^2 = (2x - 5y)(2x + 5y)$
$x^2 - 1 = (x - 1)(x + 1)$

Ejemplo Resuelto: Simplificación por Diferencia de Cuadrados 🔍

Reactivo Modelo PAA:

Simplifica la fracción algebraica: $\frac{x^2 - 49}{2x - 14}$

✅ Solución Paso a Paso:
1. Numerador: Diferencia de cuadrados $x^2 - 7^2 = (x - 7)(x + 7)$.
2. Denominador: Factor común $2$: $2x - 14 = 2(x - 7)$.
3. Fracción: $\frac{(x - 7)(x + 7)}{2(x - 7)}$.
4. Cancelamos $(x - 7)$ en ambos: $\mathbf{\frac{x + 7}{2}}$.

Regla de Oro #2

Factorización de Trinomios: $x^2 + bx + c$ 🎯

Buscamos dos números $p$ y $q$ tales que:

$$p + q = b \quad \text{y} \quad p \cdot q = c \implies (x + p)(x + q)$$
Ejemplo: $x^2 + 5x + 6$.
¿Qué dos números sumados dan 5 y multiplicados dan 6? ➔ $2$ y $3$.
Factorización: $\mathbf{(x + 2)(x + 3)}$.
Ejemplo Guiado #2

Ejemplo Resuelto: Trinomio con Signos Opuestos 🔍

Reactivo Modelo PAA:

Factoriza el trinomio: $x^2 - 3x - 28$

✅ Solución Paso a Paso:
1. Como el producto es $-28$ (negativo), los dos números deben tener signos diferentes.
2. Como la suma es $-3$ (negativo), el número de mayor valor absoluto es negativo.
3. Pares que multiplican 28: $(1, 28), (2, 14), (4, 7)$.
4. Vemos que $+4 - 7 = -3$ y $(4)(-7) = -28$.
5. Factorización = $\mathbf{(x - 7)(x + 4)}$.

Machete PAA

Machete de Factorización 📋

Diferencia de Cuadrados
$a^2 - b^2 = (a-b)(a+b)$. Clave absoluta para cancelar fracciones.
Trinomio Cuadrado Perfecto
$a^2 \pm 2ab + b^2 = (a \pm b)^2$.
Suma y Multiplicación
Busca factores del número final que sumen o resten el del centro.
Factor Común Primero
Antes de usar fórmulas complejas, revisa si hay un número o letra repetida en todos los términos.
