1. ¿Qué es el valor absoluto en la vida real? 🚶

💡 La Distancia de Tus Pasos:

Imagina que estás parado en el punto cero ($0$) de una calle:

• Si caminas 5 metros hacia adelante (+5), recorriste 5 metros.

• Si caminas 5 metros hacia atrás (-5), ¿recorriste distancia negativa? ¡NO! Tus piernas caminaron exactamente 5 metros.

Eso es el valor absoluto: la distancia al cero, y las distancias SIEMPRE son positivas o cero.

Definición Visual

$|+7| = 7$ $|-7| = 7$ $|0| = 0$

⚠️ LA TRAMPA NÚMERO 1 DE LA PAA:

Si te ponen: "Resuelve $|2x - 5| = -3$".

¡NO hagas ningún cálculo algebraico! Un valor absoluto NUNCA puede ser negativo. La respuesta es: No tiene solución (conjunto vacío).

2. Ecuaciones con Valor Absoluto: Los Dos Caminos ✌️

Para resolver $|\text{algo}| = c$ (con $c > 0$), se abren obligatoriamente dos caminos:

Camino 1: El Positivo (+)

Quitas las barras y dejas el número positivo igual:

$$\text{algo} = +c$$

Camino 2: El Negativo (-)

Quitas las barras e igualas al número en negativo:

$$\text{algo} = -c$$

Ejemplo con números: Resuelve $|x - 3| = 7$

• Camino 1: $x - 3 = 7 \implies x = 7 + 3 = \mathbf{10}$

• Camino 2: $x - 3 = -7 \implies x = -7 + 3 = \mathbf{-4}$

Comprobación: $|10 - 3| = |7| = 7$ ✓ y $|-4 - 3| = |-7| = 7$ ✓. Ambas son soluciones correctas.

3. Inecuaciones: El 'Sándwich' vs 'Las Alas' 🥪

🥪 Caso MENOR ($|x| < a$): SÁNDWICH

La $x$ queda atrapada adentro entre los dos panes (uno negativo y uno positivo):

$$-a < x < a$$

Ejemplo: $|x| < 4 \implies -4 < x < 4$.

🦅 Caso MAYOR ($|x| > a$): ALAS

La $x$ se escapa hacia los extremos exteriores (alas abiertas):

$$x < -a \quad \text{ó} \quad x > a$$

Ejemplo: $|x| > 4 \implies x < -4 \text{ ó } x > 4$.

4. Ejemplo Resuelto Paso a Paso: Inecuación Sándwich ✍️

Reactivo Clásico PAA:

Encuentra el conjunto solución para la inecuación: $$|2x - 1| \le 7$$

Resolución sin saltos:

Paso 1 (Identificar el signo): Como tiene $\le$ (menor o igual), es un sándwich.

Paso 2 (Armar el sándwich de 3 partes):

$$-7 \le 2x - 1 \le 7$$

Paso 3 (Despejar el centro): Primero eliminamos el $-1$ sumando $+1$ a las tres partes:

$$-7 + 1 \le 2x \le 7 + 1$$ $$-6 \le 2x \le 8$$

Paso 4 (Dividir entre 2 a las tres partes):

$$\frac{-6}{2} \le x \le \frac{8}{2} \implies -3 \le x \le 4$$

En notación de corchetes: $\mathbf{[-3, 4]}$.

6. Machete Resumen y Puente a la Práctica 🚀

📏 Distancia Pura
El valor absoluto siempre es $\ge 0$. Si $|expr| = -k$, no tiene solución.
✌️ Dos Caminos
Para $|expr| = c$, resuelve $expr = +c$ y $expr = -c$.
🥪 Sándwich ($<$)
$|x| < a \implies -a < x < a$. Despeja operando los 3 lados a la vez.
🦅 Alas ($>$)
$|x| > a \implies x < -a$ ó $x > a$. Dos intervalos separados.
